# Detalytics screen-flow board

Open `index.html` to inspect the editable stakeholder-review board.

## Exports

- `assets/exports/detalytics-screen-flow-board.png`
- `assets/exports/detalytics-screen-flow-board.pdf`
- `assets/exports/participant-dashboard-cohort.png`
- `assets/exports/shared-cohort-progress.png`
- `assets/exports/program-aggregate-summary.png`

The PNG is exported at the board's native 3200 × 2857 dimensions. The PDF uses one
custom 680 × 610 mm landscape page matched to the rendered board ratio, with consistent
8 mm margins. All current-screen captures retain their full 430 × 932
mobile viewport without cropping or stretching.

The three separate PNG files isolate the proposed screens for detailed stakeholder
review: the revised participant dashboard, shared cohort progress, and program
aggregate summary.

## Status key

- Current: screenshot from the working demo
- Revised: existing screen with proposed cohort additions
- Revision connector: replaces the current dashboard; it is not a navigation step
- New: proposed screen
- Unavailable evidence: documented current limitation, not a live product screen

The board is not a clickable prototype. It documents navigation, screen purpose, proposed changes, progress calculation, and privacy boundaries.
